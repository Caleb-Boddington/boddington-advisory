# Boddington Advisory

The website for Boddington Advisory, an IT consultancy for small businesses in the UK.
It is a single static page served by GitHub Pages at [boddingtonadvisory.co.uk](https://boddingtonadvisory.co.uk).

## What it is

One HTML file (`index.html`) with its styles and scripts inline. The only thing it loads from
elsewhere is its fonts, from Google Fonts. No build step, no framework, no tracking.

## Run it locally

Open `index.html` in any browser. Nothing needs installing.

## How it is hosted

GitHub Pages publishes the `main` branch. The `CNAME` file tells Pages to serve it on
boddingtonadvisory.co.uk; the domain's DNS points at GitHub.

## Known limitations

- First version, 30/09/2026. The design is a starting frame and will change.
- No contact form: the page shows an email address only.
